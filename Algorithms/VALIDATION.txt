RESTORATION EVIDENCE
- original_sources.py compares all 27 files with the recovery ZIP plus
  explicit, reviewable correctness corrections. See RESTORATION_BUG_FIXES.patch.
- All 27 original-contract examples pass.
- Shortest paths use independent all-pairs distances and negative-cycle tests.
- MST uses an independent cut-growing oracle; SCC uses mutual reachability.
- Flow is checked by enumerating every source/sink cut on small graphs.
- Bridges and articulation points use direct removal/component counting.
- Edge blocks use simple-cycle equivalence, plus a parallel-edge regression.
- Tree queries use direct ancestor walks; subtree sums use direct summation.
- Rerooting uses all-vertex distances, including a 70,000-node path whose
  endpoint sum exceeds int. The Windows depth test reserves a 128 MiB stack;
  this does not imply the original recursive code works with any judge stack.
- Range sums, assignments, and rectangle additions use naive arrays/grids.
- Mo uses the original positive-value frequency-equals-value query.
- Pattern matching uses direct string comparisons, including overlaps.
- A fixed Rabin-Karp regression has separate collisions under the two
  moduli at different positions; the corrected intersection returns zero.
- Grid words use independent per-word DFS and compare the actual word set.
- Miller-Rabin uses trial division for small/random numbers, known
  pseudoprimes, and full unsigned-64-bit boundary cases.
- Overflow regressions cover long paths, MST totals, rectangle sums,
  replacement deltas, total flow, and dense negative cycles.
